# Motivation

## 1. Why was Go developed?

Go was created by Google in 2007.

Open-sourced in 2009.

So why do we need yet another programming language? What is its purpose? How is it better or different?

Utilizing Multi-Threading efficiently. Up until today, concurrency needed to be taken into consideration within the code. Developers needed to write code to prevent conflicts when multiple tasks are running in parallel, updating the same data.

That where the main purpose and difference of Go comes in.

- ✅ Go was **designed to run on multiple cores** and built to support concurrency
- ✅ Concurrency in Go is **cheap** and **easy**

We will see more on that when we learn about Goroutines.

## 2. Go Use Cases?

The main use cases for Go:

- Apps that need to be very performant.
- Running on modern scaled, distributed systems

## 3. Characteristics of Go

Taking the simplicity of a high level programming language like `python`, and combine it with the speed of a lower level language like `C++`.

- **Simple** Syntax
- **Fast** build time, start up, and run
- Requires fewer resources
- Compiled language - compiles into a single binary (machine code)
- Cross platform

## 4. Who is using Go?

Here are some famous software that was written in `Go`:

- Docker
- HashiCorp Vault
